# ✂️ FramesWallet Guru — Freelance Editing Team Website

A professional portfolio and service website built for a freelance video editing team.

## ✨ Features
- 🎨 Clean, modern UI showcasing the team's editing work
- 📁 Portfolio/showreel section
- 📬 Contact form for client inquiries
- 📱 Fully responsive design
